# Instrucciones para el agente

Antes de analizar o modificar este proyecto, leer completamente
[AI_GUIDELINESS.md](./AI_GUIDELINESS.md) y la base compartida en la revisión que
ese documento indica. Seguir esa cadena de lectura en cada sesión de trabajo.
Si no se puede acceder a las reglas, comunicarlo antes de implementar.
Preservar cambios existentes y respetar las instrucciones de mayor prioridad.
